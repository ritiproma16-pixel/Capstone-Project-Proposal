# A Fluorescence-Based, Proximity-Gated CRISPR-Cas12a Biosensing Platform for Dual-Marker Detection of α-Synuclein on Neuron-Derived Extracellular Vesicles

## Abstract
Early Parkinson's disease diagnosis requires detecting α-synuclein on neuron-derived extracellular vesicles (EVs). This project proposes a dual-recognition AND-gate DNA logic coupled with CRISPR-Cas12a. Split DNA initiators (S1, S2) conjugated to L1CAM and α-synuclein binders require simultaneous binding on an intact EV to trigger hairpin assembly and Cas12a activation, generating fluorescence. The platform aims for low-background, high-specificity detection.

## Hypothesis
Simultaneous proximity binding of both markers on a single EV reconstitutes a Cas12a trigger, enabling specific detection of α-synuclein-positive neuronal EVs.

## Objectives
1. Design and construct dual-aptamer AND-gate.
2. Validate specificity in solution and model membranes.
3. Evaluate performance on Parkinson's-relevant cell-derived EVs.

## Methods
- **Cell culture:** SH-SY5Y wild-type and A53T mutant.
- **EV isolation:** Differential centrifugation, ultracentrifugation.
- **Probe design:** Antibody/aptamer-DNA conjugates via click chemistry.
- **Validation:** Fluorescence assays, gel electrophoresis, bead/liposome models.
- **EV testing:** Magnetic bead capture, Cas12a assay, Western blot.
